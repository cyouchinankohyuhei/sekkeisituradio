## 本人に確認中の質問
1. 1階と2階の横の位置関係（2階は1,365長い。左右どちらの端がそろっているか）
2. 階段のつながり（2階に2か所、1階に3か所）
3. 2階で斜線が引かれた910の帯は何か
4. 2階右端の455の帯は何か
5. 1階の床の間・洗面脱衣・フロの幅の内訳と、フロの段差の意味
6. 1階の店舗にある縦線（左から約5,000mm）は何か
7. 小さな四角＝柱、「＋」＝窓や出入口の端、と読んでよいか
8. 方位（上が北か）と、左上の「Z4」の意味

## 質問への回答（本人より）
1. 1階と2階の横の位置関係：2階が両側に飛び出している → 壁の位置が重なることから「左に910、右に455（縁側）」と推定（確認待ち）
2. 階段：2階の撮影スペースの階段は書き忘れ。階段は図の上下（同じ位置）でつながる
3. 2階の斜線の帯：押入
4. 2階右端の455の帯：縁側
5. 床の間・洗面脱衣・フロの幅：「1820」との回答 → 床の間455・洗面脱衣1,365・フロ1,820と解釈（確認待ち）。フロの段差は、台所の壁が風呂側に食い込んでいる部分（約910×455と推定）
6. 店舗の縦線：段差（左から7,280＝2階の和室と洋室の境の真下と推定）
7. 四角＝柱、「＋」＝引き違い窓
8. 方位：左斜め下が北（「Z4」は「N」を傾けて書いた方位記号）

## ステップ2の確認結果（本人より）
- 1〜3はOK（2階は左に910、右に455飛び出す／床の間455・洗面脱衣1,365・フロ1,820／台所の壁の食い込みは910×455）
- 4の店舗の段差は読み違い。そこには何もない（用紙のマス目の線が写り込んだもの）→ 削除済み
- 5の洋室の階段は、1階の階段（土間・WCの列）の真上に合わせる → 2F座標 10010〜11375 に移動済み

## ステップ3：骨組みDXF（作成済み）
